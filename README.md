# FinGuard AML

**FinGuard AML** — учебный веб-сервис на ASP.NET Core 8.0 для автоматизированной оценки риска финансовых транзакций. Разработан в рамках практических работ по дисциплине «Цифровые возможности для бизнеса». Приложение не предназначено для работы с реальными клиентами, финансовыми организациями или принятия юридически значимых решений.

## Назначение и пользователи

Сервис принимает сведения о переводе, обмене валют или выводе средств, переводит сумму операции в рубли, применяет демонстрационные правила оценки риска и возвращает результат в JSON. Он подходит студентам, преподавателям и разработчикам для изучения REST API, HTTP, OpenAPI/Swagger и интеграций.

## Возможности

- Приём транзакций и расчёт оценки риска `riskScore` (0–100).
- Категоризация риска: `LOW` (0–29), `MEDIUM` (30–59), `HIGH` (60–100).
- Получение официальных курсов валют через XML-сервис Банка России.
- Проверка физических лиц (`PERSON`) и организаций (`COMPANY`) через OpenSanctions, **если настроен API-ключ**.
- Получение списка обработанных транзакций и поиск по GUID.
- Валидация данных и возврат соответствующих HTTP-кодов.
- Интерактивная документация Swagger UI в локальном режиме Development.

Правила скоринга являются демонстрационными, **не заменяют требования 115-ФЗ и не служат основанием для автоматической блокировки операций**.

## Технологии и архитектура

| Компонент | Технология / назначение |
|---|---|
| Платформа | C#, ASP.NET Core Web API, .NET 8 |
| Описание интерфейса | OpenAPI 3 / Swagger UI, Swashbuckle.AspNetCore 6.6.2 |
| Controllers | Приём HTTP-запросов и возврат результатов |
| Models | Модели транзакции, результата оценки, валютного курса |
| Services | Скоринг, внешний скрининг, получение курса и хранилище |
| Хранилище | `TransactionStore`, оперативная память; СУБД пока нет |
| Внешний API №1 | Банк России: `https://www.cbr.ru/scripts/XML_daily.asp` |
| Внешний API №2 | OpenSanctions: `https://api.opensanctions.org/match/default` |
| Кеш | `IMemoryCache` для полученных курсов |
| Развёртывание | Docker / Amvera, контейнерный порт 8080 |

**Важно:** после перезапуска контейнера сохранённые в оперативной памяти транзакции исчезнут.

## Маршруты API

| HTTP | Маршрут | Назначение | Успех | Возможные ошибки |
|---|---|---|---|---|
| POST | `/api/v1/risk-score` | Рассчитать риск и сохранить результат | 201 | 400, 503 |
| GET | `/api/v1/transactions` | Получить список транзакций | 200 | — |
| GET | `/api/v1/transactions/{id}` | Найти транзакцию по GUID | 200 | 404 |
| GET | `/api/v1/rates/{currency}` | Получить курс валюты к RUB | 200 | 400, 503 |

### Пример запроса POST /api/v1/risk-score

```json
{
  "clientId": "TEST-001",
  "amount": 2000,
  "currency": "RUB",
  "transactionType": "TRANSFER",
  "senderCountry": "RU",
  "receiverCountry": "RU",
  "counterpartyName": "Учебная компания",
  "counterpartyType": "COMPANY",
  "operationsLast30Days": 2,
  "totalAmountLast30Days": 3000
}
```

Допустимые значения `transactionType`: `TRANSFER`, `EXCHANGE`, `WITHDRAWAL`. Тип `counterpartyType`: `PERSON` или `COMPANY`. Коды валют — трёхбуквенные, например `RUB`, `USD`, `EUR`.

В ответе с кодом **201 Created** возвращаются поля `transactionId`, `clientId`, `amount`, `currency`, `amountRub`, `rubPerUnit`, `rateDate`, `riskScore`, `riskLevel`, `triggeredFlags`, `screeningStatus`, `recommendation` и время расчёта. Точный результат зависит от данных запроса и ответов внешних сервисов.

### Учебные правила расчёта риска

| Условие | Баллы |
|---|---:|
| Сумма в RUB от 600 000 | +35 |
| От 20 операций за 30 дней | +20 |
| Оборот за 30 дней от 2 000 000 | +15 |
| Разные страны отправителя и получателя | +15 |
| Возможное совпадение в OpenSanctions (`score >= 0.85`) | +50 |

Итог ограничен 100 баллами. `POSSIBLE_MATCH` — только возможное совпадение, требующее ручной проверки. Без ключа OpenSanctions сервер возвращает `NOT_CONFIGURED` и рекомендацию `MANUAL_REVIEW`.

## Локальная установка и запуск

1. Установить .NET 8 SDK и Visual Studio с компонентом **ASP.NET и веб-разработка**.
2. Открыть `FinGuardAML.sln` в Visual Studio либо перейти в папку `FinGuardAML`, где лежит `FinGuardAML.csproj`.
3. Восстановить зависимости и собрать приложение:

   ```powershell
   dotnet restore
   dotnet build
   ```

4. Запустить приложение в режиме Development:

   ```powershell
   dotnet run --environment Development
   ```

5. Открыть `https://localhost:7063/swagger` (если используется HTTPS-профиль из Visual Studio). Фактический порт определяется настройками запуска и отображается в консоли.

OpenAPI JSON доступен локально по пути `/swagger/v1/swagger.json`.

## Настройка OpenSanctions

API-ключ **не добавляется в исходники или appsettings.json**. Для локальной разработки в папке проекта:

```powershell
dotnet user-secrets set "OpenSanctions:ApiKey" "ВАШ_КЛЮЧ"
```

Для облачной среды применяется переменная окружения `OpenSanctions__ApiKey`; не включайте её в GitHub и скриншоты. Публичный тестовый сервер размещён без ключа, чтобы не расходовать лимит внешнего API.

## Запуск в Docker и Amvera

`Dockerfile` и `amvera.yaml` находятся в папке `FinGuardAML` рядом с `FinGuardAML.csproj`. В Amvera выбрано окружение Docker, контейнерный порт 8080. Проект опубликован на тестовом HTTPS-домене:

`https://finguardaml-megalord9.msk1.amvera.tech`

Примеры:
- `GET https://finguardaml-megalord9.msk1.amvera.tech/api/v1/transactions`
- `GET https://finguardaml-megalord9.msk1.amvera.tech/api/v1/rates/USD`

В облачной версии Swagger UI **по умолчанию отключён**, поскольку сервер использует окружение Production. Это не мешает обращаться к API через Postman. Для практической №5 Swagger UI проверяется при локальном запуске в Visual Studio.

## Тестирование

Для локальных и облачных проверок использовались Postman и Swagger UI. Подтверждены сценарии: получение списка (200), создание транзакции (201), поиск по существующему GUID (200), расчёт высокого риска (201, score 70), получение курса USD (200), отрицательная сумма (400) и поиск несуществующего GUID (404).

## Ограничения

- Учебный проект без настоящих платёжных операций.
- Нет постоянной БД и пользовательской аутентификации.
- Нет подтверждения личности контрагента по одному совпадению имени.
- Публичный учебный API не следует использовать с персональными данными.
- Swagger UI открыт только в среде Development.
